# Historical laboratory sources

These files preserve the earlier SD and SSH/RAM transition work. They are **not an installer for another camera**. Fixed process IDs, expected backup hashes and the previous working layout are historical assumptions. Documentation IPs have been sanitized and are unusable on a real LAN.

The SD preparation script destroys the selected removable disk. The SSH transition scripts can alter process ownership, networking and init state. NOR preparation/programming sources in internal-firmware also require fresh image/recovery/hardware gates. Review source rather than executing these directories to explore them.

Do not revive frame probes or guessed vendor API calls. Use the current docs for the validated architecture and its limits. Old per-camera backups, images, credentials and U-Boot binary artifacts are deliberately absent.
