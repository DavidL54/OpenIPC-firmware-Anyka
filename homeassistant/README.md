# Anyka Controls 0.3.0

Custom integration and Lovelace card for the experimental camera API. Supports the shared camera preset database and startup selection. It is not part of Home Assistant core.

See [installation and limitations](../docs/home-assistant.md), [preset API](../docs/http-api.md) and [camera behavior](../docs/presets.md). Credentials belong only in the HA server-side config entry. The current config flow/card assumes one camera and fixed entity names.
