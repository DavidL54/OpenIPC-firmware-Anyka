# Security reports

No dedicated private vulnerability reporting address has been configured for this experimental port. Use the repository hosting platform's private reporting facility if available, or obtain an agreed private maintainer channel before sending sensitive details. Do not publish a working credential, secret-bearing firmware dump or surveillance recording in an issue.

The camera requires a trusted LAN/external VPN; Digest does not encrypt media or commands. Read docs/security.md for current trust boundaries and known limitations. There is no claim of an independent security audit or guaranteed response SLA.
